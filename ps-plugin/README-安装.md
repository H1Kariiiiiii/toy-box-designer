# 开发者模式一键安装（Windows）

把本插件装到 Photoshop 的 CEP 扩展目录并开启开发者模式（免签名加载）。

## 使用方法

右键本脚本 → **使用 PowerShell 运行**（或打开 PowerShell 执行）：

```powershell
powershell -ExecutionPolicy Bypass -File install-dev.ps1
```

脚本会：
1. 把整个 `ps-plugin/` 复制到 `%APPDATA%\Adobe\CEP\extensions\com.toybox.psplugin\`
2. 写入注册表 `HKCU\Software\Adobe\CSXS.8 / CSXS.9 / CSXS.10 / CSXS.11` 的 `PlayerDebugMode=1`（覆盖 PS 2018~2021+，多余项无害）

## 在 Photoshop 中打开插件

1. 启动 Photoshop（2018~2020）
2. 菜单 **窗口 → 扩展功能 → 玩具包装盒设计助手**
3. 面板右下角点 **测试 PS 连接**，应显示"已连接 PS Photoshop 20.0.x"

## M1 验证清单

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开面板 | 五个页签（AI 生成/模板/合规/3D/设置）正常显示，无空白 |
| 2 | 点「测试 PS 连接」 | 状态变绿"已连接 PS Photoshop xx" |
| 3 | 模板页：默认 360×500mm、300dpi，点「新建展开图文档」 | PS 新建文档 **4252×5906px**（360×300/25.4≈4252） |
| 4 | 输入名称点「创建图层组」 | 文档里出现"合规信息"图层组 |
| 5 | 切换各页签 | 无 JS 报错（可按 F12 开发者工具看控制台） |

> 换算核对：300dpi 下 1mm = 300/25.4 ≈ 11.811px，360mm → 4252px，500mm → 5906px。

## M2 验证清单（AI 生图 → 一键入文档）

> 前置：M1 清单 1~5 通过。接口设置默认**火山方舟 Seedream**（与独立版同 Key/模型可复用，OpenAI 兼容可换任意平台）；若用公司独立版已配置的 Key，直接粘贴即可。

| # | 操作 | 预期 |
|---|---|---|
| 1 | AI 生成页：展开「🔑 接口设置」，填 API Key → 切走再切回 | 值保留（已存 `%APPDATA%\ToyBoxDesignerPlugin\config.json`） |
| 2 | 填提示词点「✨ 生成主视觉」 | 状态转圈，约 15~40 秒后缩略图出现，状态变绿 |
| 3 | 点缩略图 | 选中高亮，下方显示"已选第 N 张" |
| 4 | 点「🔄 再来一张」 | 同 seed 重新生成一张相近图（无 seed 时随机） |
| 5 | 数量填 3 点「⚡ 批量」 | 依次生成 3 张（seed 递增），缩略图 3 张 |
| 6 | 模板页先「新建展开图文档」（360×500mm@300dpi），回 AI 页选中图，展开「📐 放入文档位置」设 x=60 y=60 宽=200 高=200，点「📥 放入文档」 | PS 文档出现「主视觉」图层组，内含智能对象，图片等比缩放居中于 (60,60)~(260,260)mm 区域（实际约 200×200mm 内） |
| 7 | 关闭 PS 重启后打开面板 | AI 页接口设置仍保留；生成/入文档功能正常 |

> 说明：放入为**等比缩放（不拉伸）居中**于目标区域；目标区域默认 200×200mm，M3 模板落地后会自动按盒型 front 面板计算。
> 注意：CEP Node 侧为 Node 7.7/8.6（无 fetch），已用内置 http/https 实现，**无需 node_modules**；网络请求全部走 Node 侧（面板 XHR 跨域受限）。

## M3 验证清单（盒型刀模 / 合规 / 条码）

> 前置：M1/M2 清单通过。M3 起模板页重写为**盒型工作流**：选盒型 → 尺寸 → 新建文档 → 画刀模线；旧"手动创建"折叠在页面底部（M1 兼容）。

| # | 操作 | 预期 |
|---|---|---|
| 1 | 模板页：默认天地盖 200×130×60mm、出血 3mm，点「📄 新建展开图文档」 | PS 新建文档，尺寸 = 展开净尺寸 + 两侧出血（如天地盖 260×~361mm + 6mm → 约 3142×4346px @300dpi），`box-info` 显示展开/出血尺寸 |
| 2 | 点「✂ 画刀模线」 | 出现「刀模线」图层组（已锁定），内含线稿图层：每个面板黑色轮廓 + 折边橙色线条 + 橙色出血框，位置与展开图面板吻合 |
| 3 | 切换「开窗盒」「双插盒」，改尺寸后重复 1~2 | 展开图尺寸/面板数变化正确（开窗 10 面板、双插 9 面板、天地盖 18 面板） |
| 4 | 展开条码区：格式 EAN-13，输入 13 位货号（如 6901234567892） | 校验通过（hint 不显示错误） |
| 5 | 点「📥 条码入文档」 | 出现「条码」图层组，条码（白底含数字）等比放置到该盒型条码面板中心（天地盖=底面、开窗=底面、双插=背面） |
| 6 | 输入错误位数（如 12 位） | hint 提示"需要 13 位数字"，不生成 |
| 7 | 合规页：勾选目标市场（如 中国+欧盟）+ 填品名/货号/材质，点「📋 排入文档」 | 「合规信息」图层组出现文字图层，位于合规面板（天地盖=盖后围边），字号随面板自适应；CE/CCC 加粗文字在块右侧 |
| 8 | 合规块与条码同面板的盒型（开窗/双插）先排合规再放条码 | 条码自动下移避让（合规占上面 50%） |
| 9 | 切换页签/重启面板 | 无 JS 报错；模板页/合规页功能正常 |

> 说明：刀线=黑色实线、折线/出血框=橙色实线（虚线增强列为 M5 打磨项）；CE/CCC 圆框同样 M5 打磨（当前为加粗文字）。
> 图层组织：展开图文档 = 「刀模线」（锁定）＋「合规信息」＋「条码」＋「主视觉」＋ 背景。
> 交互注意：合规与条码同面板的盒型（开窗/双插）自动 50/50 上下分区，放置顺序无关；若先排合规后条码自动下移，先放条码则合规块自动限上半区。
> 所有入文档内容的坐标均相对展开图（自动加出血平移）；文字行基线锚点与字号换算待实机微调（M5）。

## M4 验证清单（3D 预览 + 截图入文档）

> 前置：M1~M3 清单通过。3D 页签内置 three.js **r128**（Chromium 57/61 WebGL1 兼容，本地化于 `lib/`，无 CDN）。

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开 3D 页签（无需 AI 图） | 出现 canvas 预览区，显示当前盒型的 3D 盒子（纯色面板+标签），可拖拽旋转、滚轮缩放 |
| 2 | 在 AI 页生成一张主视觉后切回 3D 页 | 盒子正面自动贴上生成图（等比 contain）；点「🔄 刷新预览」重贴 |
| 3 | 模板页切换盒型（天地盖/开窗/双插）后回 3D 页 | 3D 盒型随之变化（天地盖六面全贴、开窗背面留空、双插全贴），尺寸比例正确 |
| 4 | 点「📸 截图入文档」 | 「3D 预览」图层组出现截图，等比缩放居中放入默认区域（60,60,200,200mm） |
| 5 | 修改截图位置（如 300,60,150,150）再截图 | 截图放入新位置（相对展开图自动加出血平移） |
| 6 | 连续多次刷新/切换盒型 | 无显存累积崩溃（纹理/几何已 dispose）；控制台无报错 |

> 说明：3D 展开图由面板自绘（面板矩形+主视觉图+标签），与独立版 mockup 视觉一致；相机距离按盒型最大边长自动适配。
> 独立版 mockup.js 的 `texFlip` 在 boxes.js 中未定义，插件版同样不启用（左右围边 90° 旋转已移植）。

## 调试

- 面板内按 **F12** 打开 CEP 调试器（Chromium DevTools，需 PS 2018+）
- 修改代码后重新运行 `install-dev.ps1` 覆盖，然后**重启 Photoshop** 生效（或关闭重开面板）

## 常见问题

- **菜单里看不到插件**：确认 `%APPDATA%\Adobe\CEP\extensions\com.toybox.psplugin\CSXS\manifest.xml` 存在；确认注册表 PlayerDebugMode=1；PS 必须完全退出后重启
- **面板打开是空白**：按 F12 看控制台报错；确认 CSInterface.js 存在
- **PS 2018 打开提示"无法加载扩展"**：确认 manifest 的 Host Version 覆盖 PS 应用版本（PS 2018=19.0，当前 `[19.0,22.9]`）

## 卸载

```powershell
Remove-Item "$env:APPDATA\Adobe\CEP\extensions\com.toybox.psplugin" -Recurse -Force
```
（注册表项可保留，无害）
