# 玩具包装盒设计助手（Toy Box Designer）

澄海玩具电商公司设计部专用：AI 生成玩具包装盒主视觉 + 自动贴入盒型展开图 + 条码 + 合规自查 + 300dpi/出血导出。
桌面应用，双击即可使用。

> 📋 **测试与缺陷记录**：完整 Bug 清单（65 项，全部已修复）见 [BUGS.md](BUGS.md)；64 个硬断言随每次打包自动回归（SMOKE 环境，失败即退出码 1）。

## 功能（v0.2.8）

- **AI 主视觉生成**：豆包 Seedream 5.0（火山方舟），支持 2K/4K、Seed 复现、图生图
- **图片比例 × 清晰度**：比例（1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 3:2 / 2:3 / 21:9）+ 清晰度（720p / 1080p / 2K / 4K）组合出像素，或自定义任意 宽x高（长边自动封顶 4096）
- **组图生成**：一次生成 1-6 张（正面/背面/侧面/顶部/展开图/细节），缩略图点选切换应用到展开图
- **批量出图**：一次用不同随机 Seed 生成 2/4/6 个方案对比，点缩略图切换方案
- **历史方案库**：每次生成自动存档（参数+图+合规排版），列表回看、点击载入复用、可删除；**缓存清理自动保护方案引用图片**
- **方案导出/导入**：历史方案打包成 .toybox.json（含图片），同事间互发导入即用（轻量团队共享）
- **图生图**：选一张产品照片做参考图，AI 以产品为主体重绘包装主视觉
- **3D mockup 预览**：展开图自动折叠为 3D 盒子（three.js，拖拽旋转/滚轮缩放），给客户看成品效果
- **合规信息自动排版**：填产品信息（品名/货号/材质/标准/警告语）→ 自动排入展开图对应面板，勾选市场自动加 CE/3C 标志，与条码同面板自动避让；**排版信息随历史方案存档/恢复，导出/导入 `.toybox.json` 一并携带**
- **质检（新增）**：导出前自动检查主视觉/必印信息/条码校验位/出血/文字溢出（fail 阻止导出、warn 确认放行）；可选 **AI 视觉质检**（默认小米 MiMo `mimo-v2.5`，也可切换任意 OpenAI 兼容视觉模型：doubao-vision/通义等；检查生成图有无文字/水印/畸形）
- **印刷稿导出（PDF/X-3 + CMYK）**：内置 Ghostscript 10.07，一键导出可发印刷厂的 PDF/X-3、CMYK、3mm 出血（TrimBox/BleedBox 精确标注）
- **盒型展开图**：天地盖 / 开窗盒 / 双插盒，长宽高参数化刀模，AI 图自动贴入主视觉面板
- **条码**：EAN-13 / UPC-A / Code128 叠加到条码面板（白底 + 缩放适配）；**输入即时校验**（位数/校验位错误红字提示且不绘制）
- **合规自查**：目标市场（中国内销 / 欧盟 / 美国）必印信息清单 + 印刷参数提示，**支持全部勾选/取消全部**
- **导出**：300dpi PNG，可选 3mm 出血（含成品线示意）

## 快速开始

### 1. 准备文生图 API Key（默认火山方舟 Seedream）

1. 打开 https://console.volcengine.com/ark （火山引擎方舟控制台），注册/登录；
2. 左侧「开通管理」→ 开通 **豆包 · 图像生成模型（Seedream）** 服务（5.0 lite / 5.0 pro）；
3. 左侧「API Key 管理」→ 创建 API Key（`sk-` 开头）；
4. 「模型广场」确认你的模型 ID（默认 `doubao-seedream-5-0-260128`，即 Seedream 5.0 lite）。

> **兼容任意 OpenAI 兼容文生图平台**：设置 →「图片生成接口地址」可填硅基流动 / 智谱 CogView /
> 阿里通义万相 / OpenAI gpt-image-2 等（下拉有预设），换平台只改地址 + 模型 ID + Key 三项。
> - 火山方舟：JSON 接口，支持组图、图生图（JSON 内联参考图）、Seed 复现、watermark 关闭；
> - 其他平台（含 OpenAI gpt-image-1/2）：文生图走 `/images/generations`，图生图自动走
>   `/images/edits`（multipart，gpt-image-2 官方支持 inpainting 编辑），组图自动降级为单图；
>   Seed 透传（不支持的平台会报错，清空 Seed 即可）。
> - OpenAI gpt-image-2 模型 ID 为 `gpt-image-2`（快照 `gpt-image-2-2026-04-21`），
>   尺寸支持 1024x1024 / 1024x1536 / 1536x1024 等（以官方文档为准）。

> 模型 ID 以火山方舟控制台「模型广场」显示为准，填入应用「设置 → 模型 ID」。
> 档位与价格参考（2026-08 调研）：5.0 pro `doubao-seedream-5-0-pro-260628`（1K/1.5K/2K，0.30/0.60 元每张，支持局部重绘）；
> 5.0 lite `doubao-seedream-5-0-260128`（2K/3K/4K，0.22 元/张）；4.5 `doubao-seedream-4-5-251128`（0.25 元/张）；4.0 `doubao-seedream-4-0-250828`（0.20 元/张）。
> 4.5/4.0 输出固定 JPEG，5.0 系列可 PNG（应用已按图片实际格式自动识别）。

### 2. 运行

- **开发运行**：双击 `start.bat`（首次会自动装依赖，稍慢）；
- 或命令行 `npm start`。

### 3. 使用流程

1. 左侧「设置」粘贴 API Key → 点「保存设置」（只存在本机）；
2. 选择盒型（天地盖 / 开窗盒 / 双插盒），可改长宽高（mm）；
3. 填写产品主题、年龄、风格，提示词自动生成（可手动微调）；
4. **（可选）** 选一张产品照片作为参考图 → 提示词自动追加"以参考图为主体"；
5. **（可选）** 填 Seed（如 42）可复现同一构图；点「🎲 同 Seed 再来」换风格不换构图；
6. **（可选）** 「生成张数」选 2/3/4/6 → 一次出多张（正面/背面/侧面/展开图…），点缩略图切换贴入展开图的那张；
7. 点「✨ 生成主视觉」→ AI 出图后自动贴入展开图主视觉面板；
8. **（可选）** 条码面板填 13 位 EAN/12 位 UPC → 勾选"在展开图上绘制条码"；
9. 左侧「合规检查」勾选目标市场 → 按清单自查必印信息；
10. **（可选）** 勾选「自动排版合规信息到展开图」并填写品名/货号/材质/标准/警告语 →
    信息块自动排入展开图对应面板（天地盖→盖围边、开窗盒→底面、双插盒→背面），
    勾选的市场自动叠加 CE / 3C 标志，与条码同面板时自动上下分区不重叠；
11. 点「⬇ 导出展开图 PNG」→ 300dpi 导出（可勾选/取消 3mm 出血）；
12. 点「📄 导出印刷 PDF/X」→ 一键导出 PDF/X-3 + CMYK + 3mm 出血印刷稿（直接发印刷厂）。
    顶部会显示「✓ PDF/X 引擎就绪」；若显示缺引擎，说明应用资源不完整；
13. 底部「🧊 3D mockup 预览」自动把展开图折叠成 3D 盒子——拖拽旋转、滚轮缩放，
    切换盒型/尺寸/主视觉图时实时更新（给客户/老板看成品效果）；
14. **（可选）批量出图**：点「⚡ 批量出图」+ 选择 2/4/6 方案 → 用不同随机 Seed 生成
    多个方案对比，点缩略图切换方案（批量完成也自动存档）；
15. **历史方案库**：左侧「🗂 历史方案」列出所有已存档方案（缩略图+时间+盒型+提示词），
    点击载入（恢复盒型/尺寸/提示词/图，可直接再导出），⤴ 导出为 .toybox.json 文件，✕ 删除；
16. **方案共享**：点「📥 导入」选同事发来的 .toybox.json → 自动入库并载入预览，
    参数与图片完整恢复（微信/QQ/U盘传文件即可，跨电脑复用方案）；
17. **质检**：每次点导出都会自动跑本地质检（主视觉/必印信息/条码校验位/出血），未通过会阻止导出；
    也可在左侧「🔍 质检」面板手动运行「✅ 本地质检」，或点「🖼 AI 视觉质检」检查生成图有无文字/水印/畸形。
    **视觉质检模型**默认小米 MiMo（`mimo-v2.5`），接口地址/模型下拉可选火山方舟 doubao-vision、
    OpenAI gpt-4o、智谱 GLM-4V、通义 qwen-vl、硅基流动 Qwen2.5-VL 等任意 OpenAI 兼容视觉模型；
    「视觉质检 API Key」**必填，填你自己创建的视觉模型 Key**（不复用上方文生图 API Key）；
18. **多配置档（多 API Key）**：设置页顶部「当前配置档」可**新建/删除/切换**多套配置——
    每档独立保存 文生图 Key/接口/模型 + 视觉质检 Key/接口/模型（如"火山方舟（公司）"、"MiMo（个人）"），
    生成与质检用当前选中的档；老配置自动迁移为「默认档」。

## 项目结构

```
main.js               Electron 主进程（窗口 / 配置 / Seedream API / 图片格式识别 / 文件保存）
preload.js            安全桥接层
templates/boxes.js    ★ 盒型模板库（参数化刀模 + 条码面板，核心资产）
renderer/
  index.html          界面
  style.css           样式
  app.js              交互逻辑（提示词 / 图生图 / seed / 条码 / 合规 / 展开图渲染 / 出血导出）
  compliance.js       合规清单数据（中国/欧盟/美国必印信息，来自法规调研）
  vendor/JsBarcode.all.min.js  条码生成库
start.bat             双击开发运行
build.bat             双击打包 exe
config.example.json   配置示例（真实配置存于 %APPDATA%/toy-box-designer/config.json）
```

## 设计思路（为什么这样架构）

**核心原则：AI 负责"好看"，模板引擎负责"能印"。**

- 文生图模型不擅长精确的印刷文件（文字出错、分辨率不足、无出血/刀模线）——
  联网调研确认 OpenAI gpt-image 官方 Limitations 也明说"文本渲染、构图精确定位不可靠"，
  所以让它只生成**主视觉插画**（提示词已强制"无文字、主体居中、留安全边距"）；
- 盒型结构是纯数学：`templates/boxes.js` 里每个盒型 = `长宽高 → 展开图坐标`，
  刀模结构永远正确，新增盒型只需加一个 `build()` 函数；
- 条码、出血、成品线、安全边距全部由排版代码生成，AI 不参与几何；
- 中文文字：一律"AI 出无字图 + 代码叠字"，避免模型写出错别字（Seedream 5.0 pro
  已支持多语种文字渲染，后续可评估直接在图上出字）。

## 方案导出/导入技术说明

- 导出：历史方案打包为 `.toybox.json`（含 app 标识/版本号 + 全部参数 + 图片 base64 内嵌），单文件可微信/QQ/U盘传递；
- 导入：解析校验（`app === 'toy-box-designer'`）→ 图片 base64 落盘到本机 `images/` → 自动入库并载入预览，盒型/尺寸/提示词/Seed/模型完整恢复；
- 缺图（文件丢失）导出时置 null，导入跳过，不影响其它字段；
- 用途：设计部同事间交换方案、备份到移动硬盘、客户确认稿归档。

## 批量出图与历史方案库技术说明

- **批量出图**：串行调用文生图 API（每次随机基准 Seed 递增，同一提示词），完成后结果区显示方案缩略图（标注「方案 1/2/…」），点击载入该方案的全部视图；批量结果自动逐条存档；
- **历史方案库**：每次生成（单图/组图/批量）自动存档到 `%APPDATA%/toy-box-designer/schemes/manifest.json`（最多 100 条，图片复用 `images/` 目录的本地文件不重复拷贝）；
- 载入方案会恢复盒型、尺寸、提示词、模型、Seed 和全部视图图，可直接继续编辑/导出；删除仅移除索引，图片文件保留（避免误删共享资源）；
- 缩略图经 IPC 按需读取本地图片，列表最多展示最近 30 条。

## 合规自动排版技术说明

- 在「合规检查」面板填写产品信息后勾选「自动排版」：信息块（品名/货号/材质/执行标准/制造商/警告语）自动绘制到各盒型的 `compliancePanel`（天地盖→盖后围边、开窗盒→底面、双插盒→背面）；
- 勾选目标市场自动叠加**示意标志**：欧盟→CE 圆环标志、中国→CCC 圆环（简化矢量，正式出图请替换为合规认证图形）；
- 与条码同面板时自动上下分区（条码下移、信息块居上），不重叠；
- 信息块为白底圆角（模拟印刷白墨区），字号随面板宽度自适应，超长文本自动截断；
- 数据来源见 `renderer/compliance.js`（法规清单）与「合规与印刷参数」小节；标志仅为设计示意，正式印刷前需按认证机构规范替换。

## 3D mockup 技术说明

- 用 three.js（r185）把展开图**各面板裁剪为纹理**，贴到按面板真实尺寸拼装的 3D 盒子上（六面独立 PlaneGeometry，避免纹理变形）；
- 各盒型在 `templates/boxes.js` 的 `mockup3d.faces` 里声明六面与展开图面板的对应关系（如天地盖：盖面→顶、底面→底、四围边→四侧面）；开窗盒背面无设计则留空；
- three.js + OrbitControls 已用 esbuild 打包为单文件经典脚本 `renderer/vendor/mockup.bundle.js`（约 785KB，无运行时依赖、无 CDN），规避 file:// 下 ES module 不可用的问题；
- 拖拽旋转（阻尼）、滚轮缩放，底部网格地面衬托。

## 印刷稿（PDF/X）技术说明

链路：展开图 SVG（含 3mm 出血）→ Chromium `printToPDF`（sRGB PDF，页面精确 mm）→
**内置 Ghostscript 10.07.1** `-dPDFX=3 -sColorConversionStrategy=CMYK` 转 PDF/X-3。

- 页面尺寸含 3mm 出血（MediaBox）；**TrimBox = 成品线（内缩 3mm），BleedBox = 页面边**，印刷厂可直接按框线开刀；
- 颜色统一转 CMYK（default_cmyk ICC），图像 RGB 自动色域映射；
- 已验证输出含 `GTS_PDFXVersion / PDF/X-3:2002` 标记；
- Ghostscript 已捆绑进应用（`resources/gs/`，约 25MB），无需用户安装；
- 实现踩坑备忘：printToPDF 的 pageSize 单位实测是**英寸**（非文档所述微米）；gs 10 默认 SAFER 需 `-dNOSAFER` 才能读 ICC；出血偏移须经 `setpagedevice` 传页面设备参数（单位 pt）。

## 合规与印刷参数（调研依据摘要）

- 中国：3C（CCC）目录含玩具（CNCA-C22-02，2026-11-01 新版实施）；GB 6675-2025
  （2026-11-01 实施）；产品质量法第 27 条必印信息（品名/厂名厂址/合格证明/警示）。
- 欧盟：CE 标志（两字母等高、最小 5mm）；TSD 2009/48/EC 附件 V 警告语**原样照抄**；
  0-3 岁窒息警告；2030 起需数字产品护照（DPP）数据载体。
- 美国：CPSIA / ASTM F963；CPC 证书；包装必印 **Tracking Label**（制造商、生产地
  点与日期、批次号、工厂地址）；UPC（GS1 US）。
- 印刷：出血 3mm（英制 1/8in）、刀线出血约 6mm、安全边距、≥300DPI、CMYK、刀模线单独图层。
- 完整清单在 `renderer/compliance.js`，可自行增删条目；出口前请与检测机构/客户最终确认。

## 已知边界（MVP）

- 合规标志（CE/CCC）为简化矢量示意，正式印刷前需替换为认证机构规范图形；
- 方案文件为 JSON 单文件（含 base64 图片，几 MB~20MB），团队实时协作仍需服务器；批量出图耗时为 方案数×单张耗时。

## 常见问题

- **生成报错「文生图 API 调用失败」**：多半是 Key/模型 ID 不对，或该模型未开通；去方舟控制台核对「模型广场」的 ID。
- **Seedream 5.0 lite 不支持 1K**：5.0 lite 最低 2K；若用 1K 请切换到 5.0 pro 或 4.0。
- **组图报错/不出多张**：5.0 pro 不支持组图（界面有提示）；组图请用 5.0 lite / 4.5 / 4.0；另组图对 4.5/4.0 输出为 JPEG。
- **条码没出现**：EAN-13 需 13 位数字（校验位须正确），UPC-A 需 12 位；编码非法时条码不绘制。
- **中文文字**：默认 AI 图强制无文字，文字由排版引擎叠加，避免错别字。
- **版权**：提示词默认不含知名 IP；请勿输入迪士尼/奥特曼等 IP 名生成侵权形象。
